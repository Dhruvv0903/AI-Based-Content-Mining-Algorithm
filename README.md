# AI Based Content Mining Algorithm

A Streamlit app that recommends movies using content-based filtering and collaborative filtering on the MovieLens dataset.

## Features
- Movie search with partial title matching
- Content-based recommendations
- Collaborative recommendations
- Analytics dashboard
- Genre explorer
- Clean Streamlit UI

## Tech Stack
- Python
- Streamlit
- Pandas
- SciPy
- Scikit-learn

## Setup
1. Clone the repository
2. Install dependencies
3. Download the MovieLens dataset
4. Put the CSV files inside the `MovieLens/` folder
5. Run the app with:
   ```bash
   streamlit run app.py
